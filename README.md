Formulário de Cadastro - Exercício HTML

Este repositório contém um exercício simples em HTML que demonstra como criar um **formulário de cadastro**.

📝 Descrição

O objetivo deste projeto é praticar a criação de formulários em HTML. O formulário inclui campos comuns de cadastro como:

- Nome  
- E-mail  
- Senha  
-cadastrar (button)

💡 Tecnologias Utilizadas

- HTML5

> Este projeto **não** utiliza CSS ou JavaScript. É focado exclusivamente na estrutura HTML.

📂 Estrutura dos Arquivos

```

exercicioHTML/
│
├── index.html        # Página principal com o formulário
└── README.md         # Este arquivo

````
